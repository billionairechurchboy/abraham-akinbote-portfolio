# Abraham Akinbote: Portfolio

Personal portfolio site for Abraham Akinbote, Brand Designer & Growth Engineer.

Plain HTML, CSS and JavaScript. There is no build step, so open `index.html` or serve the folder with any static host.

- `index.html`: home page (banner, work wheel, about, skills, experience, contact)
- `portfolio.html`: full portfolio, filtered by category
- `assets/js/media.js`: every image, video and website shown on the site (Cloudinary links)
- `assets/js/main.js`: site behaviour
- `assets/js/intro.js`: load screen
- `assets/css/style.css`: styles
- `assets/cv/`: CV PDF
